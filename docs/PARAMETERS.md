# Parameters

Generated by `zederia-cli params --format md` from the parameter registry (`core/src/params/Registry.cpp`). Do not edit by hand; a test fails when this file is out of date.

864 parameters in 123 modules; 760 are exposed to the host.

## How to read the tables

- **Id** is permanent. The host's 32-bit parameter id is a hash of it, so adding parameters never renumbers existing ones.
- **Range** and **Default** are in the unit shown. `%` values are stored as fractions: 0.25 means 25 %. Levels at or below -72 dB are silence.
- **Skew** is how the host's 0..1 value maps onto the range: `linear`, `log` (equal steps are equal ratios) or `power n` (range x position^n, fine resolution near the minimum).
- **Smoothing**: `none` is taken as is at the next control tick, `control` is smoothed at the control rate (every 16 samples), `sample` is also interpolated per sample.
- **Host**: exposed to the host for automation. **Mod**: can be the destination of a modulation route.
- **Scope**: `voice` values exist once per voice, `global` values once per instrument. A route is polyphonic when both its source and destination are per-voice.
- **Patch field** is the JSON pointer of the value inside a patch document. Choices are written as their names, switches as `true`/`false`.
