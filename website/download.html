Install in four steps

  1. Download and run the installer. A browser may say the file is not commonly downloaded: choose Keep.
  2. Get past SmartScreen. The installer is not code-signed yet, so Windows may show “Windows protected your PC”. Click More info, then Run anyway.
  3. Allow the administrator prompt. Windows asks once. Then choose the parts: VST3, CLAP, Standalone and agent tools; the factory content is always installed.
  4. Open your host. Let it scan for plug-ins. In FL Studio: ADD › Refresh plugin list (fast scan).
Check the file first. In PowerShell, Get-FileHash .\ZederiaSetup-1.0.1.exe must print the SHA-256 above. If Smart App Control is on in Windows 11, it blocks unsigned installers and offers no Run anyway.

What goes where

VST3 plug-inC:\Program Files\Common Files\VST3\Zederia.vst3
CLAP plug-inC:\Program Files\Common Files\CLAP\Zederia.clap
Standalone, agent tools, manualC:\Program Files\Zederia
Factory content%PROGRAMDATA%\Zederia\Factory
Factory presets, to browseDocuments\Zederia\Presets
Your presets and filesDocuments\Zederia

Hosts find the plug-ins in these standard folders, with no extra search folder to add.

For AI agents

Connect an agent

Install the agent tools, then add zederia-mcp to your agent. To let it work on the instance you are playing, switch on Agent link on that instance's AGENT page.

Claude Code 
> claude mcp add zederia -s user -- "C:\Program Files\Zederia\zederia-mcp.exe" --stdio

For Codex and Antigravity, Client setup on the AGENT page copies the configuration or a setup prompt. The agent guide is also served to agents by the server.

Requirements

  • Windows 10 or 11, 64-bit, on an x64 processor (AVX2 is used when present)
  • A VST3 or CLAP host, or the Standalone app
  • About 90 MB of disk space

Upgrading and uninstalling

Run a newer installer over the one you have. To remove Zederia, use Settings › Apps › Zederia. Both keep your presets and settings in Documents\Zederia.

Earlier versions are on the releases page.
