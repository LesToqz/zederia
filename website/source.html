Build from source

Four scripts, one machine

You need Windows 11 with Visual Studio 2022 Build Tools (MSVC v143), CMake and Ninja. The dependencies are fetched at pinned versions; the installer also needs Inno Setup 7.

  • 390 automated tests across the engine, plug-in and agent server
  • The plug-in validated with pluginval and clap-validator
  • Every factory preset checked by the content check
PowerShell 
> git clone https://github.com/LesToqz/zederia.git
> cd zederia
> scripts\build.ps1        # Release build in build\release
> scripts\test.ps1         # build and run every test
> scripts\install-dev.ps1  # a per-user development install
> scripts\package.ps1      # the installer, with Inno Setup 7
